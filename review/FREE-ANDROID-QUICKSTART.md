ILMIGO DIGITAL ACADEMY — FREE ANDROID OFFLINE BETA

1. Download the latest Android debug artifact ZIP using the release link.
2. Extract app-debug.apk. Open it on Android and permit installation from
   that browser/file manager if Android asks. GitHub download may require sign-in.
3. Keep an existing installation and its app data when updating. Do not
   uninstall or clear data simply to install an update: local progress can be lost.
   Debug builds may use different signing keys; if Android rejects an update, stop.
4. Choose your learning language and English/Urdu explanation language.
5. Open Learning path and select a lesson. The suggested plan is 30 minutes:
   review 5, words/patterns 8, read/listen 7, speak/write 7, assessment 3.
6. Use Listen when a matching device voice is available. If missing, check
   Android text-to-speech settings and supported voice downloads. Some voice
   engines and optional recognition need internet; not every language is supported.
7. In Speaking studio, listen/repeat or type the target phrase and Compare words.
   This matching aid is not a pronunciation score.
8. Profiles, completed lessons, XP and writing drafts stay on this device.
   There is no cloud backup in this edition. Use the parent PIN for child profiles.

No account/purchase is needed for bundled lessons in this edition. Cloud AI,
email sync and billing are not active. Calendar reminders open an external
calendar service and may need internet/account access; they are optional.

168 draft lessons: English/Urdu 20 each; other 32 languages four beginner lessons
per language. These are not complete professional courses or qualified language/
audio approvals. No physical-phone test or signed store release has been claimed.
