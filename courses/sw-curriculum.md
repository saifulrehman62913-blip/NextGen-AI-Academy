# ILMIGO · Swahili introductory foundation

Original draft: qualified language and audio review pending. Three suggested 30-minute practice sessions. Not a complete professional course.

Reading, partner drill, writing and four answer-key checks per lesson. Roman aids are approximate.

## Greetings and courtesy

Swahili Habari asks for news/how things are; a common reply is nzuri. Samahani can attract attention or express an apology. Some numbers change with noun class when counting actual objects; these are standalone forms.

**Daily plan:** 5m review, 8m words/patterns, 7m read/listen, 7m speak/write, 3m assessment.

- Habari — Hello / greeting / سلام / ملاقات (Habari)
- Kwaheri — Goodbye / leaving / رخصت ہونے کا جملہ (Kwaheri)
- Asante — Thank you / شکریہ (Asante)
- Tafadhali — Please / request / درخواست میں شائستگی (Tafadhali)

**Reading / drill**

Habari
Kwaheri
Asante
Tafadhali

Copy each target expression carefully. Cover the model and write it from memory. Match each expression to its meaning. Practise saying all four with a partner; for counting, take turns in order. Do not treat the drill as a natural conversation.

**Quiz answer key**

- Choose the taught expression for: Hello / greeting. → Habari
- Choose the taught expression for: Goodbye / leaving. → Kwaheri
- Choose the taught expression for: Thank you. → Asante
- Choose the taught expression for: Please / request. → Tafadhali
