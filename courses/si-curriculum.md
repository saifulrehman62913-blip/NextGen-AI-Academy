# ILMIGO · Sinhala introductory foundation

Original draft: qualified language and audio review pending. Three suggested 30-minute practice sessions. Not a complete professional course.

## Greetings and courtesy

Sinhala uses a left-to-right script. Aayubowan is a respectful greeting. Gihin ennam is a leaving expression. Roman spellings here are approximate; vowel length and consonant contrasts require listening practice.

**Daily plan:** 5m review, 8m words/patterns, 7m read/listen, 7m speak/write, 3m assessment.

- ආයුබෝවන් — Hello / greeting / سلام / ملاقات (aayubowan)
- ගිහින් එන්නම් — Goodbye / leaving / رخصت ہونے کا جملہ (gihin ennam)
- ස්තුතියි — Thank you / شکریہ (stutiyi)
- කරුණාකර — Please / request / درخواست میں شائستگی (karunaakara)

**Reading / drill**

ආයුබෝවන්
ගිහින් එන්නම්
ස්තුතියි
කරුණාකර

Copy each target expression carefully. Cover the model and write it from memory. Match each expression to its meaning. Practise saying all four with a partner; for counting, take turns in order. Do not treat the drill as a natural conversation.

**Quiz answer key**

- Choose the taught expression for: Hello / greeting. → ආයුබෝවන්

- Choose the taught expression for: Thank you. → ස්තුතියි
- Choose the taught expression for: Please / request. → කරුණාකර
